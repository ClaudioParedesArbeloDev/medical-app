## 🇪🇸 Español

### Qué es

Primeros pasos de una app para que cada persona registre y recuerde su historial médico. Por ahora incluye la base del proyecto multiplataforma, splash animado con **Lottie** (adaptado a escritorio y móvil), login y pantalla de inicio.

> 🚧 En desarrollo.

### Cómo correrlo

```bash
git clone https://github.com/ClaudioParedesArbeloDev/medical-app.git
cd medical-app
flutter pub get
flutter run
```

---

## 🇬🇧 English

### What it is

Early stage of an app that helps people record and remember their medical history. It currently includes the cross-platform project base, an animated **Lottie** splash screen (responsive for desktop and mobile), login and home screens.

> 🚧 Work in progress.

### Running it

```bash
flutter pub get
flutter run
```
